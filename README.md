# 思维框架实战课

一套把「想清楚、说清楚、做明白」拆成 12 个可练习课件的实战课程。每课一个独立 HTML 页面，含首屏演示动画、交互练习、自测题与作业复盘模板，手机和电脑都能直接打开。

作者：Albert Huang

## 在线阅读

打开 [index.html](index.html) 进入课程地图，点击任意一课即可开始学习。

## 本地使用

```bash
git clone <本仓库地址>
# 直接用浏览器打开 index.html，或起一个静态服务：
python3 -m http.server 8080
```
