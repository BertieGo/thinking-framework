01

别再只盯一个点

同一个问题反复出现，就是系统在说话

系统思考就一句话：不问"谁的错"，问"是什么结构让这事反复发生"。你看到的延期、bug、加班、离职率，都不是孤立事件，而是一张网里的一个读数。

单点思维的典型反应：出问题了，找到那个"点"——那个人、那次操作、那个数字——然后摁下去。结果呢？葫芦摁下去，瓢浮起来，过段时间老问题换个马甲又回来。

练一练：点开看看，这些"点"背后是什么

你看到的点新人出错多

点开看结构

背后是回路：老员工没时间带 → 新人全靠自己摸 → 出错多 → 被批评 → 更不敢问 → 错更多。换个人来，一样转。

你看到的点某个数字掉了

点开看结构

数字只是存量的一个读数，像血压。血压高了吃降压药是治标，搞清"什么在持续往血管里加压"才是治本。

你看到的点项目又延期了

点开看结构

延期是果，长在下游。因在上游：需求膨胀、排期拍脑袋、返工循环。在果上催进度，等于在水池出水端拼命舀水。

系统思考的问法结构是什么

点开看问法

换成三个问题：谁在放大谁（回路）？什么东西在慢慢积累（存量）？我的行动多久才见效（延迟）？问完，力气才花得对地方。

记住：当同一个问题反复出现，别怪运气，也别怪具体的人——是系统在稳定地生产这个结果。你要修的是结构，不是人。

02

反馈回路：两种转圈法

越滚越快，还是拉回稳态

系统里的因果不是直线，是环：结果会反过来影响原因。只有两种环——增强回路让变化滚雪球，平衡回路把系统拉回目标线。

增强回路恶性循环

点开看链条

加班 → 疲劳 → 出错多 → 返工多 → 时间更少 → 更要加班。每转一圈，情况更糟一分。上面 hero 里那颗越转越快的红球，就是它。

增强回路良性循环

点开看链条

产品好用 → 用户口碑好 → 更多人用 → 反馈和收入变多 → 产品更好。增强回路不分好坏，只负责"放大"——方向取决于你踩进哪一头。

平衡回路恒温器

点开看机制

太热就制冷，太冷就加热，温度永远围绕设定值波动。它的作用是"纠偏"：偏离目标越远，拉回来的力越大。

平衡回路价格回归

点开看机制

供过于求 → 降价 → 需求上升 → 供不应求 → 涨价。价格被供需双方来回拉扯，围绕一个"合适点"上下浮动，自己会回来。

怎么分：问一句——"这个动作会让结果越来越大，还是把它拉回原点？"越来越大 = 增强；拉回原点 = 平衡。分不清的时候，把因果链倒着念一遍就清楚了。

03

存量与流量：一只水池

水位是存量，进水管出水管是流量

把任何系统想成一只水池：存量是池子里现在的水位（团队健康度、知识储备、库存现金），流量是进水管和出水管（每天投入、每天消耗）。

水位不取决于某一天进多少水，取决于进和出的长期差值。团队今天加不加班是流量；团队还剩多少战斗力、还能扛几周——那是存量，是你真正的家底。

试一试：拖动「加班强度」，看团队水位

滑块 = 每天的加班强度（流量）。池子水位 = 团队健康度（存量，数字为示意）。注意看：你松手后，水位不是立刻动的——它慢半拍才变。

04

延迟：行动和见效之间的时间差

你以为没用，其实水还在路上

上一节水池里，你应该注意到了：松手后水位慢了一拍才动。这就是延迟——流量变存量，需要时间。健身三个月才见体型，读书半年才见谈吐，代码质量一两个迭代后才见稳定性。

延迟本身不可怕，可怕的是人按"即时反馈"的直觉去操作它，于是连踩三个坑：

坑一加码过猛

点开看后果

行动后没立刻见效，以为力度不够，继续加码。两拨效果叠在一起到达时，直接过冲——药下猛了，症状好变成了新问题。

坑二过早放弃

点开看后果

见效太慢就停手，可存量其实还在慢慢变好。你在黎明前撤了手，前面所有的投入跟着清零——前功尽弃这四个字，大半是延迟造成的。

坑三来回摇摆

点开看后果

今天 A 方向、明天 B 方向，系统永远在响应上一个动作，永远稳不下来。船还没掉头，你又打满反方向舵。

解法把见效时间写进预期

点开看做法

做任何动作前先问：这事正常多久见效？学习按季度看，不按天看；质量按迭代看，不按当天看。预期里有延迟，手就不会乱抖。
05

治标 vs 治本：杠杆点在哪

在系统上游轻轻一刀，胜过下游拼命舀水

职场经典场景（数字均为示意）：一个项目组排期偏紧，开始长期加班。点开下面这条链，看看恶性循环是怎么一圈圈闭合的。

1排期紧，开始加班流量加大：投入时间变多›

初期确实顶用：靠加班把进度追回来了。这是典型的延迟——短期内水位（进度）看着稳住了。

错觉："加班有用，再顶一顶就过去了。"
2疲劳累积，质量下降存量变坏：团队健康度水位在漏›

人不是机器，连续高压之后：评审走马观花、测试偷工、联调埋雷。这些"小毛病"当时看不见，因为质量影响要一两个迭代后才兑现——又是延迟。

信号：线上 bug 密度悄悄爬升（示意：比基线高出一截）。
3返工变多，时间更少出水管开大：时间被返工抽走›

修 bug、回炉、补联调，把本来就不够的时间再抽走一块。进度不但没追回，反而差得更多了。

恶性循环闭合：缺时间 → 加班 → 质量差 → 返工 → 更缺时间。每转一圈，水位更低。
4本能反应：继续加人加班在下游使劲，等于往漏水的池子里加水›

这是大多数人的应对：再撑一撑、再招两个人、再压一轮排期。注意——这些动作全加在出水管的下游，池子还在漏。

为什么没用：增强回路没被切断，加水的速度追不上漏水的速度，还顺手把新人也卷进了循环。
5杠杆点：需求管理在上游切一刀，回路从源头停转›

真正的杠杆点在需求端：砍掉低价值需求、冻结两周内的变更、把排期按真实产能重排。出水管的口子先堵上，水位才止得住。

区别：继续加班 = 在下游拼命舀水（治标）；管住需求 = 在上游关水龙头（治本）。力气小十倍，效果大十倍。

判一判：下面这些动作，治标还是治本？

场景一：bug 频发，团队决定"今晚加班把 bug 连夜修完"。
治标。修完这批，下批照样来——bug 是加班循环的症状，不是病根。真要动手，查 bug 密度为什么在涨。
场景二：需求天天变，团队决定"两周内冻结需求变更，新需求进排队池"。
治本。它切的是上游水龙头：需求膨胀被卡住，下游的返工和加班会自己停下来——这就是平衡回路在起作用。
场景三：团队 burnout、离职率走高，决定"多发团建、搞outing、发水果"。
治标。关怀可以短期缓冲，但只要加班回路还在转，水位继续漏。员工要的不是水果，是回得了家的排期。

口诀不追单点追回路，不拼蛮力找杠杆。

动作之前先定位：这一刀切在回路的哪一段？切在上游需求和结构上，是杠杆；切在下游症状和人身上，是自费力气。

06

自测：五道题

答对 4 题，这课就过
1. 什么叫"增强回路"？
增强回路 = 滚雪球：好的越好，糟的越糟。它放大方向，不负责纠偏。
2. 恒温器把室温维持在设定值附近，属于哪种回路？
平衡回路的任务就是纠偏：偏离目标越远，拉回来的力越大，围绕目标波动。
3. 水池比喻里，"当前水位"和"每天进水量"分别是？
存量 = 现在池子里剩多少（家底）；流量 = 每天进出多少。家底看的是长期差值，不是单日。
4. 你按了个动作，两三天没看到效果，正确的做法是？
加码过猛和过早放弃，都是用即时反馈的直觉对付延迟。先定"见效周期"，再决定动不动手。
5. 团队加班恶性循环里，杠杆点最可能在哪？
继续加班和发福利都是下游治标。杠杆在回路的上游——先关水龙头，池子才止得住漏。
